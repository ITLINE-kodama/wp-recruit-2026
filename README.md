# wp-recruit-2026

WonderPrax 株式会社 採用サイト デザイン案（モックアップ）

提案・打合せ用のプレビュー。本リポジトリは ITLINE がコンペ提案資料として制作したものです。

## アクセス

公開 URL（GitHub Pages）にはパスコード認証ゲートが設定されています。
パスコードは ITLINE 担当（小玉）より関係者へ別途共有しています。

## 構成

| ファイル | 内容 |
|---|---|
| `index.html` | 採用LP本体（10セクション構成） |
| `style.css` | デザイン CSS（ゲート含む） |
| `script.js` | スクロール／reveal／パスコードゲート |
| `assets/` | 画像（WonderPrax 現コーポレートサイト由来） |

## セクション

1. HERO — メイン集合写真と大型コピー
2. MESSAGE — 代表メッセージ
3. WHY US — 3 つの差別化軸
4. NUMBERS — 採用倍増、4 本柱などの数値
5. JOB — 募集職種（コンサルタント／セールス）
6. MEMBER VOICE — メンバー紹介
7. A DAY — 1 日の流れ
8. PROCESS — 選考フロー
9. FAQ — よくある質問
10. ENTRY — エントリーCTA

## ローカル起動

```bash
python -m http.server 5180
# → http://127.0.0.1:5180/
```

## 注意

- 本サイトはコンセプト案であり、実装版ではありません。
- 写真は WonderPrax 様 現コーポレートサイトから一時的に流用しています。本番制作時は撮り下ろし／差し替えを想定しています。
- メンバー名・職種詳細・年収レンジ等の数値はサンプル値です。
